# AnalyzerBoardInformation

Настольное приложение на Qt (Widgets) для мониторинга данных ARINC 429: чтение слов ARINC 429 с плат PCI429/MPC429 под Linux, распаковка параметров, отображение в таблицах и на графиках в реальном времени, логирование принятых данных в файлы. Личный проект, разрабатывался в 2016–2017 гг.

## Возможности

- Добавление устройств — приёмных каналов плат ARINC 429 (типы: PCI429 и MPC429) через диалог со статусом и описанием платы; для PCI429 поддерживаются каналы с номерами 1–8 и выбор банка 0/1.
- Периодическое чтение буфера канала и разбор 32-битных слов: 8 бит — адрес, 22 бита — данные, 1 бит — матрица состояния (МС), 1 бит — чётность; параметры группируются по адресу.
- Настройка типов параметров: десятичные (с константой распаковки), дискретные (с именованными состояниями битов), смешанные; конфигурация регистрируемых параметров сохраняется в файл и читается из него.
- Отображение: главное окно с областью QMdiArea; для каждого устройства — MDI-окно с таблицей параметров (столбцы: Имя, Значение, Всё слово, Ед.изм., МС, Адрес), таблицей дискретных параметров и окнами графиков изменения параметров во времени.
- Логирование принятых слов в двоичные файлы `./Logs/temp/<плата>_channel_<N>.log` (QDataStream) с периодической ротацией; фоновое чтение логов для восстановления данных по параметру.
- Настраиваемые интервалы (в мс) обновления данных, таблиц, графиков и записи в файл; прореживание истории графика.

## Архитектура

- `MainController` — главный контроллер: хранит платы, устройства и их потоки; слоты добавления/удаления устройства, настройки параметров, запуска и остановки.
- `Device` (абстрактный) / `ArincDevice` — обёртка над каналом платы: создаёт модель данных `ArincReader` и MDI-представление устройства.
- `ArincReader` — модель данных (`ArincModelInterface`): по QTimer читает буфер канала, раскладывает слова по адресам, пишет лог и оповещает наблюдателей `ArincParametrObserver` (таблицы и графики).
- `ArincBoards/` — интерфейсы `ArincBoardInterface` / `ReadingBuffer` и их реализации: `ArincBoardlPCI429` (обмен с драйвером платы через ioctl-команды, объявления в `pci429LNX.h`) и `ArincBoardMPC429` (заготовка без реализации обмена).
- `UnpackingArinc/` — иерархия параметров `Parametr → ArincParametr → ArincDecParametr / ArincDiscrParametr / …` и `DataArinc32` — разбор 32-битного слова ARINC.
- `LogsManager` / `FileReader` — запись логов и их чтение в отдельном потоке; `GrafikManager` — создание окон графиков и подписка наблюдателей; `SettingsDevice` — настройки устройства (интервалы, загрузка данных из лога).
- `FormsModels/` — представление: `MainView` (QMainWindow + QMdiArea), `MdiForm` / `MdiFormDiscr` (таблицы на QTableView/QAbstractTableModel), `MdiGrafForm` / `ArincGrafikPanel` (графики), диалоги добавления устройства и настройки параметров.
- Каждое устройство переносится в собственный `QThread` (`moveToThread`); обмен между потоками — сигналы-слоты, доступ к параметрам защищён `QMutex`.

## Технологии

- C++ / Qt Widgets: модули `core`, `gui`, `widgets`, `printsupport` (по .pro); Qt4/Qt5-совместимое подключение widgets.
- QCustomPlot 1.3.2 (автор Emanuel Eichhammer, GPLv3) — построение графиков, исходники в `FormsModels/QCustomPlot/`.
- QDarkStyle — тёмная тема оформления (`style.qss` и ресурсы `rc/`, подключается в `main.cpp`).
- Доступ к платам — через файл устройства и ioctl-интерфейс Linux-драйвера (`ArincBoards/pci429LNX.h`); вендор платы в коде не указан.

## Структура проекта

```
AnalyzerBoardInformation.pro — проект qmake

maincontroller.{h,cpp}      — главный контроллер
device.{h,cpp}, arincdevice.{h,cpp} — устройства и их обёртка над каналом
arincreader.{h,cpp}         — модель данных (чтение, распаковка, оповещение)
settingsdevice.{h,cpp}      — настройки устройств
logsmanager.{h,cpp}         — логирование и чтение логов
grafikmanager.{h,cpp}       — управление окнами графиков

ArincBoards/                — драйверы плат PCI429/MPC429, pci429LNX.h
UnpackingArinc/             — параметры и разбор 32-битных слов ARINC

```

## Сборка

Проект собирается через qmake: `qmake AnalyzerBoardInformation.pro && make`. Целевая платформа — Linux: работа с платой идёт через `open()`/`ioctl()` (`unistd.h`, `fcntl.h`, `sys/ioctl.h`).

## Статус

Утилита разрабатывалась как рабочий инструмент мониторинга ARINC 429: 40 коммитов за период 17.10.2016 — 20.01.2017, после чего разработка прекращена. В финальной ревизии реальное чтение данных с платы PCI429 закомментировано, канал отдаёт тестовые значения (синус/косинус/случайное число) — см. `ArincBoards/arincboardpci429linux.cpp`.
